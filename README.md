# Linear & Polynomial Regression

Implementation of Linear and Polynomial Regression on the Salary dataset (Years of Experience vs Salary).

- Dataset: Salary Dataset - Simple Linear Regression (Kaggle)
- Libraries: NumPy, Pandas, Matplotlib, scikit-learn
- Notebook: LinearRegression_PolynomialRegression.ipynb
- Metrics used: R2 score, MSE, RMSE
